# Vela 全方位测试体系设计（2026-09-10）

## 目标
对 Vela 浏览器全部功能与 UI 做多级全方位测试，产出 bug 库（BUGS.md），按 P0→P1→P2 依次修复。

## 执行模式
- 自动为主：隔离 profile 测试实例 + AX 元素按压 + 整窗截图 + stderr 探针（VELA_GH/VELA_TEST dump）。
- 人工补充：手势手感、拖拽实感、视觉审美、流畅度——出带步骤的人工验收清单给用户。

## 多级任务
- L1 冒烟回归：BUILDING.md 34 个已知坑逐一回归（静态 grep 可证 + 运行时行为两类）。
- L2 功能域 ×8：D1 标签页 / D2 导航与地址栏 / D3 收藏 / D4 启航页 / D5 GitHub 同步 / D6 设置页 / D7 超级拖拽 / D8 通用 UI（右键菜单、下载、历史、隐私窗口、快捷键、中英文案）。
- L3 视觉与文案：静海主题截图核对 + dist 品牌词零残留 grep。
- L4 人工验收清单：自动化无法覆盖项（约 10-15 项）。

## 用例记录格式
每条：编号 / 域 / 操作步骤 / 预期 / 实际 / PASS-FAIL-BLOCKED / 证据（截图或日志行）。
结果落 vela/tests/RESULTS.md（运行日志）与 vela/tests/BUGS.md（bug 库）。

## BUGS.md 条目格式
`BUG-NNN [P0|P1|P2] [域] 标题`：现象、复现步骤、预期、实际、证据、状态(open/fixed/wontfix)。
P0=崩溃/数据丢失/核心不可用；P1=功能坏；P2=体验/视觉/文案。

## 修复策略
全部测完 → 先出完整 bug 报告给用户 → 用户确认优先级 → P0→P1→P2 逐个修，每修一个跑对应回归用例。

## 边界
- AX 对弹层菜单项按压不可靠 → 改键盘佐证或转人工清单。
- 测试窗口会出现在用户屏幕：按 PID 精确管理，用完即收。
- GitHub 同步用 VELA_SELFTEST 体系（独立仓 vela-sync-selftest）。
