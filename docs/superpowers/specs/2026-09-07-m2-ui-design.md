# Vela M2 — "静海" UI 设计规范

- 日期：2026-09-07
- 状态：待用户审阅
- 设计立场：**国人的效率，北欧的克制**——保留中国大陆用户 15 年沉淀的效率交互，剥离国产浏览器的廉价噪点（弹窗/红点/资讯流），以高端产品的克制感呈现。

## 1. 布局结构（默认形态：360 骨架，现代化精修）

```
┌────────────────────────────────────────────────┐
│ ●●● │ ▸标签◂ ▸标签◂ ＋          （标签栏：圆角胶囊标签，双击关闭）│
│ ◀ ▶ ↻ │ 🔒 https://…          ⭐ ⋯   （地址行：极简，星标收藏）│
│ ▸ ▸ ▸ 收藏栏（默认显示 · 可自动隐藏模式）▸ ▸ ▸   │
├────────────────────────────────────────────────┤
│                                                │
│                  网页内容区                      │
│                                                │
└────────────────────────────────────────────────┘
  左缘：Vela 侧栏（可呼出：竖标签/收藏/历史/空间，⌘E 或 hover 左缘唤起）
```

- **默认顶部标签**（尊重大陆用户根深蒂固的 Chrome/360 布局习惯，零学习成本）；**左栏模式保留为一键切换的"专注形态"**（sidebar.verticalTabs，已有能力，改为非默认）
- 收藏栏默认显示——中国用户把收藏栏当主导航用（区别于欧美搜索主导），这是 360 极速体验的根
- 无底栏、无侧边新闻、无任何默认弹窗

## 2. 配色系统（双主题）

| 语义 | 浅色「宣纸」（默认） | 暗色「石墨」 |
|---|---|---|
| 窗底/页面外 | #F7F8FA | #1C1F26 |
| 工具栏 | #FFFFFF（微投影 y=1 blur=6 α=4%） | #242933 |
| 分隔线 | #E5E7EB | #333A46 |
| 正文/标签标题 | #1F2328 | #E8EAED |
| 次要文字 | #6B7280 | #9AA3AF |
| 主色「靛青」 | #3563E9 | #5B8DEF |
| 激活标签 | 白底+投影（浅） | #2E3542（暗），底缘 2px 主色 |

- 主色只用在一处关键位置（激活标签底缘/链接/焦点态），拒绝满屏蓝
- 标签：圆角 8px 胶囊式、激活态微投影，间距 4px——Arc/Safari 的精致感，密度保持国产紧凑
- 跟随系统切换浅暗（原生 prefers-color-scheme 链路）

## 3. 大陆效率交互包（全保留，去噪实现）

| # | 交互 | 来源 | 实现层 | 阶段 |
|---|---|---|---|---|
| 1 | 双击标签关闭 | 360/全网习惯 | pref `browser.tabs.closeTabByDblclick` | M2（pref 级） |
| 2 | 收藏星标弹编辑气泡（改标题/选文件夹，360 精髓） | 360 极速 | 原生星标面板打底+皮肤化 | M2 |
| 3 | 收藏栏「自动隐藏」模式：平时收成 2px 感应线，鼠标到顶滑出（250ms 缓动） | 360 招牌 | CSS+JS（browser.xhtml 层） | M2 核心 |
| 4 | 收藏管理侧栏（树形+搜索+拖拽整理） | 360 侧栏 | sidebar 书签 panel（原生已有）+网格皮肤 | M2 |
| 5 | 新标签页「启航页」：搜索框+九宫格（按频次自适应）+每日一图（可关）；**无资讯流** | 360 导航页的高端化 | activity stream 定制 | M2 末 |
| 6 | 鼠标手势（→前进 ←后退 ↓关闭 ↗ 刷新，带轨迹指示） | 国产标配 | JS 内置实现（fork 层） | M3 |
| 7 | 超级拖拽（拖词=搜索，拖链接=后台打开） | 国产标配 | JS 内置实现 | M3 |
| 8 | 下载右上弹层（进度+完成提示，无独立窗口） | 360 | 原生下载面板皮肤化 | M2 |

## 4. Vela 差异化（高端灵魂，分阶段）

1. **命令面板 ⌘K**（M3）：搜索历史/书签/动作/设置的统一入口——高端效率件
2. **空间 Space**（M3）：工作/生活分域，各空间独立 cookie 池——Firefox 容器技术的独家强项，国产浏览器做不到的真隔离
3. 截图标注（M3+）、阅读模式强化（M3+）

## 5. M2 落地顺序（构建验证驱动）

1. pref 包：verticalTabs=false（回默认顶部）+ closeTabByDblclick=true → 18 秒增量
2. 主题包：改 browser/themes 工具栏/标签配色为「静海」体系（CSS 层，走 overlay 新机制：整文件收编）
3. 收藏栏自动隐藏模式（CSS+JS，本里程碑核心新代码）
4. 启航页简化（activity stream 去噪）
5. 每步交付用户终端 run 验收感官

## 6. 明确不做（高端取舍）

- 资讯流/广告位/红点体系（哪怕能变现）
- 默认皮肤商城、动态皮肤
- 账号弹窗、登录强提醒（同步做，静默做）
- 老板键等戏谑功能（保留静默隐私窗口快捷键即可）
